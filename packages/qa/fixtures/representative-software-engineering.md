# Software Engineering Fundamentals

## Course description
This course introduces software requirements, modular design, version control, testing, and maintainability through a small team project.

## Learning outcomes
By the end of the course, students should be able to:
- distinguish functional and non-functional requirements;
- create a simple modular design from requirements;
- use Git branches and pull requests for collaborative work;
- design unit and integration tests for critical behavior;
- review code for maintainability and explain technical trade-offs.

## Weekly topics
1. Requirements and acceptance criteria
2. Architecture and modular decomposition
3. Git workflow and collaborative development
4. Unit testing and integration testing
5. Refactoring, code review, and maintainability

## Assessment
- Assignment: convert a short product brief into requirements, acceptance criteria, and a modular design proposal. Grade out of 100.
- Quiz: assess requirements, architecture, Git, and testing concepts using a mixture of question types.
- Team reflection: discuss one engineering trade-off encountered during implementation.

## Constraints
Assessments must be grounded in the listed topics. Do not introduce cloud deployment, mobile development, or machine learning topics.
