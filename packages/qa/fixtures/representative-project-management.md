# Project Management for Digital Projects

## Purpose
Students learn to plan and control a small digital project from initiation through closure.

## Learning outcomes
- define project scope and measurable success criteria;
- build a work breakdown structure and milestone plan;
- identify project risks and propose responses;
- distinguish schedule, cost, scope, and quality trade-offs;
- communicate project status to technical and non-technical stakeholders.

## Modules
### Module 1 — Initiation and scope
Project charter, stakeholders, constraints, assumptions, scope boundaries.

### Module 2 — Planning
Work breakdown structures, dependencies, milestones, estimation.

### Module 3 — Risk and change
Risk probability/impact, mitigation, contingency, change control.

### Module 4 — Monitoring and communication
Status reporting, variance, issue escalation, project closure.

## Assessment requirements
- Individual assignment: create a lightweight project plan for a fictional website redesign.
- Quiz: cover scope, WBS, risk, change control, and status reporting.
- Include scenario-based questions rather than recall-only assessment where practical.

## Boundaries
Do not assume a specific project-management certification framework. Keep terminology understandable to undergraduate learners.
